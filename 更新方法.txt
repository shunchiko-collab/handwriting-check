手書き集計チェック v1.1（安全な写真確認版）

前回の写真から「90418」「444」などの誤認識がありました。
この版では、精度が確認されていない自動OCRの結果を数値欄に転記しません。
各項目の写真を拡大表示して、数字を目視で入力・訂正します。
「この項目を写真で確認済み」をチェックすると、空欄を0として合計し記載「計」と比較します。
Excel・CSV出力は任意です。写真は端末外へ送信しません。

【GitHub Pagesの更新】
1. ZIPを解凍してください。
2. リポジトリ handwriting-check の Code 画面で Add file > Upload files を選びます。
3. ZIPではなく、中のファイル（index.html, app.js, sw.js, など）を選択します。
4. Commit changes で上書きしてください。
5. スマートフォンでページを再読み込みしてください。古い表示が残る場合はブラウザのサイトデータを消して再読み込みします。

注意：この版は高精度OCR完成版ではありません。記載計と手書き数字の照合を安全に行うための暫定版です。
